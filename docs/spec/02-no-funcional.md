# 02 · Requisitos no funcionales (NFR)

> Guiados por ISO 25010. Deja solo los que apliquen; cada uno, verificable.

- **Seguridad**: <p.ej. solo el propietario modifica su recurso; secretos fuera del código>
- **Rendimiento**: <p.ej. la lista responde en < 1 s con N registros>
- **Usabilidad / accesibilidad**: <p.ej. contraste WCAG AA; navegable por teclado>
- **Fiabilidad**: <p.ej. errores manejados; no se pierde estado>
- **Mantenibilidad**: <p.ej. lógica de negocio en el dominio, no en el controlador>
